I spent the last few weeks building something I wish existed when I started using AI in my L&D work.

**Introducing the eLearning Prompt Library** — a free, open-source collection of production-ready AI prompts for Instructional Designers, eLearning Developers, and L&D Project Managers.

Here's the problem it solves:

Most AI prompts shared online are vague. You ask Claude or ChatGPT to "write a storyboard" and get something you spend 2 hours fixing. The prompt was the problem, not the AI.

This library takes a different approach. Every prompt uses proven prompt engineering techniques — role assignment, XML delimiters, structured output constraints, and format rules — applied specifically to eLearning workflows.

**What's inside (15 prompts across 7 categories):**

🎯 Instructional Design — Bloom's gap analysis, cognitive load audit, SME notes to lesson plan  
📝 Content Development — Storyboard shell generator, narration script writer (Ruth Colvin Clark style)  
⚙️ Storyline & Rise — Trigger/variable architecture, Rise block planner, HTML5 interaction specs  
📊 Assessment — Scenario-based question designer, question bank generator  
📋 Project Management — Effort estimator using Chapman's ratios, stakeholder update emails  
✅ QA & Review — Storyboard QA review, pre-launch course QA checklist  
🎨 AI Media — Midjourney scene prompts, ElevenLabs voiceover direction  

Built to work with [prompt-master](https://github.com/nidhinjs/prompt-master) — a Claude skill that further optimises each prompt for your specific context.

The library is free, MIT licensed, and open to contributions. If you've got a prompt that actually works, the CONTRIBUTING guide is straightforward.
